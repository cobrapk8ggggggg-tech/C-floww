كل الأعداد التالية نتائج فعلية. المصادر الخارجية ومزود الذكاء الاصطناعي في الاختبارات محاكاة.

## اختبارات التخزين والمحرك

الأمر: `node scripts/test-durable.js`، أو `npm run test:durable --prefix backend`.
يشغّل MongoDB replica set محلية ومحاكي Firestore الرسمي 1.22.0 مع التحقق من SHA-256، ثم الاختبارات. Node محليًا 24، وCI مضبوطة على 22؛ Java 21.

الحزمة الكاملة الأخيرة: **127 اختبارًا، صفر إخفاق وصفر تخطٍّ**. تشمل اختبارات المزودين والأمان السابقة، والمعاملات والأقفال، وHTTP والصلاحيات وidempotency، والنشر وإعادة القراءة على محاكي Firestore الفعلي. اختبر المسار أيضًا محول OpenAI-compatible الحقيقي عبر خادم HTTP محلي يحاكي AI؛ لا اتصال بمزود مدفوع.

ثبت في الاختبارات:
- توقف عملية Node فرعية فعلية بعد حفظ رد المزود، ثم استئناف بعامل آخر دون طلب جديد.
- استعادة الرد المحفوظ حتى لو لم تعد بيانات المزود متاحة.
- عدم احتساب غياب المصدر أو استخراج غير صالح كنجاح.
- ثبات المسرد في الترجمة الخالصة، وحفظ مصطلحات الذكي قبل تأكيده.
- انتقال آمن إلى مزود احتياطي بعد رفض مصادقة مؤكد.
- مرحلتان لمحاكاة تجهيز Qwen من عامل طويل فقط، دون تسجيل حساب فعلي.
- إلغاء طلب المزود عند انتهاء مهلته، وإيقاف امتلاك خطوات جديدة عند طلب إيقاف العامل.
- تعطل النشر ثم استئنافه دون إعادة الترجمة، وعدم استبدال الترجمة عند إعادة السحب.

## السكرابر والواجهة

- السكرابر: **14 اختبار Python/Flask ناجحًا**، وcompileall. تحميل جميع وحدات المواقع سجل 37 مصدرًا، و30 منها ذات دوال فصل مستقل؛ دون طلب أي موقع.
- الواجهة: **39 اختبارًا ناجحًا** في 5 ملفات، وTypeScript وبناء Vite ناجحان. صفحة المهام متوقفة افتراضيًا. اختُبرت قراءة التقدم بعد إعادة تركيب الصفحة، والإيقاف عبر API، وثبات مفتاح الإنشاء بعد انقطاع الشبكة. ليست جلسة متصفح متصلة بخدمات الإنتاج.
